# Квантовое состояние |2025⟩

Построение квантовой схемы, приготавливающей состояние **|2025⟩** на 7 кубитах,
и генерация соответствующего кода **OpenQASM 2.0**.

## Идея

Число 2025 — это сумма первых 45 нечётных чисел: 1 + 3 + 5 + … + 89 = 45² = 2025.
Схема готовит суперпозицию состояний вида |2k−1⟩ (нечётные базисные состояния) с
распределением амплитуд, реализованным через слой адамаров, контролируемые фазовые
вращения и каскад CNOT.

## Что внутри

- `create_2025_state()` — сборка квантовой схемы на `qiskit` (7 кубитов: слой `H`,
  `X` на младшем кубите, цепочка контролируемых фаз `cp`, каскад `cx`)
- `generate_openqasm_code()` — эквивалентная схема в формате OpenQASM 2.0

## Технологии

`Python` · `Qiskit` · `NumPy` · `OpenQASM 2.0`

## Запуск

```bash
pip install qiskit numpy
python "2025⟩ .py"
```

## Структура

```
2025⟩ .py   — построение схемы |2025⟩ и генерация OpenQASM
```
